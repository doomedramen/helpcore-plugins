You can convert between units with `convert`. Provide a value, a source unit, and a target unit from the supported categories:

**Length**: mm, cm, m, km, in, ft, yd, mi
**Weight**: mg, g, kg, oz, lb, st, ton (metric), ton_us (US short ton)
**Temperature**: c, f, k (Celsius, Fahrenheit, Kelvin)
**Volume**: ml, l, gal (US gallon), qt, pt, cup, floz (US fluid ounce), tbsp, tsp
**Speed**: mps, kmh, mph, knot
**Data**: b, kb, mb, gb, tb, kib, mib, gib, tib (SI and binary prefixes)
**Area**: m2, km2, ha, ft2, acre, mi2
**Time**: s, min, hr, day, week, year (365 days)
**Pressure**: pa, kpa, bar, atm, psi, mmhg
**Energy**: j, kj, cal, kcal, wh, kwh
**Angle**: deg, rad, grad

Unit abbreviations are case-insensitive. When the user asks to convert something, figure out the source and target units and use this tool.
