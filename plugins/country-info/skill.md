You can look up country information with `country_lookup`. It accepts a country name (e.g. "Japan", "United Kingdom"), a 2-letter code (e.g. "JP", "GB"), or a 3-letter code (e.g. "JPN", "GBR").

Returns: official name, capital, population, region/subregion, flag image URL, currencies, languages, timezones, borders, area, and demonym. Present the most interesting/relevant facts first. When the user asks comparative questions (e.g. "which is bigger, France or Germany?"), look up both and compare.
