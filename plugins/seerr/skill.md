You can request media through Overseerr or Jellyseerr:

- `seerr_search` — search for movies, TV shows, or people
- `seerr_request` — submit a request for a movie or TV show
- `seerr_trending` — see what's trending/popular
- `seerr_requests` — check the status of recent requests
- `seerr_discover` — discover recommendations based on genres, streaming services, etc.

The user must configure their Seerr URL and API key. When requesting media, always confirm before submitting. For TV shows, you can request specific seasons or the entire show.
