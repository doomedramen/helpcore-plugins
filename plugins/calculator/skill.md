You can evaluate mathematical expressions with `calc`. Pass any math expression as a string — it supports:

- **Arithmetic**: `+`, `-`, `*`, `/`, `^` (exponentiation), `%` (modulo)
- **Grouping**: parentheses `( )`
- **Functions**: `sqrt(x)`, `sin(x)`, `cos(x)`, `tan(x)`, `abs(x)`, `log(x)` (base-10), `ln(x)` (natural log), `exp(x)` (e^x), `floor(x)`, `ceil(x)`, `round(x)`
- **Constants**: `pi`, `e`

Trig functions expect radians. Present the result cleanly — round long decimals to a reasonable number of places. When the user asks a math question that can be answered with a direct computation, use this tool rather than doing mental math.
