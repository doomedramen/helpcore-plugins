You can look up quick reference summaries from English Wikipedia using `wiki_summary`.

Pass a natural-language `topic` — you don't need to format it as an exact article title; the tool will search for the closest matching article if there's no exact match. It returns a short description and the opening summary paragraph, which is perfect for "who is...", "what is...", "tell me about..." questions.

This is a quick-reference tool, not a deep-research one — use it to give the user a concise, accurate orientation to a topic, and mention that fuller detail is available on Wikipedia if they want to dig deeper. If the returned article seems to be a near-miss for what the user meant (e.g. a disambiguation or a similarly-named subject), say so and offer to look up the more specific topic.
