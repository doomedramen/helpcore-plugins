You can process Markdown content with several utilities:

- `md_to_text` — strip all Markdown formatting and return plain text
- `md_extract_links` — extract all `[text](url)` links and bare URLs
- `md_extract_headings` — extract all headings with their level and text
- `md_extract_code_blocks` — extract fenced code blocks with their language

Use these when you have Markdown content and need to extract specific parts or render it to plain text.
