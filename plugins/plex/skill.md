You can interact with a Plex media server:

- `plex_search` — search across all libraries for a movie, show, artist, or album
- `plex_recently_added` — see recently added media (optionally filtered by library type: movie/show/music)
- `plex_libraries` — list all media libraries on the server
- `plex_now_playing` — see what's currently being played and by whom

The user must configure their Plex server URL and X-Plex-Token in plugin settings. Present results naturally — show titles, years, and library names. For now-playing, show the user, what they're watching, and progress.
